# Proyecto Final – Tecnicatura Universitaria en Programación  
**Aplicación Web Administrativa para Emprendimiento de Impresión 3D**

## Descripción
Este repositorio corresponde al proyecto final de la **Tecnicatura Universitaria en Programación**.  
El objetivo es desarrollar una **aplicación web con interfaz responsiva**, orientada a la gestión administrativa de un emprendimiento de impresión 3D.  

El sistema permitirá centralizar la información de productos, ventas y gastos, automatizar cálculos de costos y ganancias, y generar reportes confiables para la toma de decisiones estratégicas.  
Además, estará diseñado para ser utilizado en ferias y eventos, soportando el uso **multiusuario en simultáneo**.

---

## Objetivos
- Registrar productos, ventas y gastos de manera organizada.  
- Automatizar cálculos de costos y ganancias.  
- Generar reportes mensuales y por producto.  
- Facilitar el acceso multiplataforma (PC, celular, tablet).  
- Permitir uso colaborativo en simultáneo.  
- Diseñar un sistema escalable que pueda crecer con nuevas funcionalidades.
